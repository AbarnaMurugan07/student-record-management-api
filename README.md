# Student Record Management REST API

## Description
A REST API developed using Go to manage student records.

## Features
- Create student records
- View all students
- View individual student
- Update student details
- Delete student records
- JSON data handling
- Logging middleware
- Concurrent request safety

## Technologies
- Go
- net/http
- JSON
- Git
- GitHub

## Run
go run main.go

## Server
http://localhost:8080
